# 业务错误码

所有错误响应遵循 RFC 9457 Problem Details，并扩展 `code` 字段：

```json
{ "type": "about:blank", "title": "Unprocessable Entity", "status": 422,
  "detail": "不能给自己的内容投票", "code": "QA-1015" }
```

## 分段约定

| 前缀 | 上下文 | 段位含义 |
| --- | --- | --- |
| `ID-` | Identity | `1xxx` 业务规则 / `2xxx` 冲突 / `3xxx` 权限 / `4xxx` 未找到 |
| `QA-` | Q&A | 同上 |
| `REP-` | Reputation | 同上 |
| `DIS-` | Discovery | 同上 |
| `AUTH-` | 认证与 CSRF | 401 / 403 / 429 |
| `SYS-` | 平台级 | 参数校验、并发冲突、未知异常 |

## HTTP 状态映射

| 领域异常 | 状态码 | 典型场景 |
| --- | --- | --- |
| `BusinessRuleException` | 422 | 违反业务规则（自投票、悬赏积分超限） |
| `ConflictException` | 409 | 状态冲突（重复采纳、悬赏已结束） |
| `ForbiddenException` | 403 | 权限不足（非提问者采纳、越权查看流水） |
| `NotFoundException` | 404 | 资源不存在或已软删除 |
| 乐观锁失败 | 409 `SYS-409-CONCURRENT` | 并发编辑同一内容 |
| 唯一约束冲突 | 409 `SYS-409-DUPLICATE` | 重复提交（如并发投票） |

## 常用错误码速查

| 错误码 | 含义 |
| --- | --- |
| `ID-1004` | 密码不满足强度要求（8–64 位，含字母与数字） |
| `ID-2001` | 学号/工号或邮箱已被注册 |
| `QA-1001` / `QA-1002` | 标题长度、正文长度不合法 |
| `QA-1005` | 标签数量必须为 1–5 个 |
| `QA-1015` | 不能给自己的内容投票 |
| `QA-1016` | 投票值只能是 +1、-1，或 0 表示撤销 |
| `QA-2002` | 问题已采纳，不能重复采纳 |
| `QA-2006` | 内容已被采纳，不能编辑 |
| `QA-3001` | 只有提问者或课程教师/助教可以采纳 |
| `QA-4001` / `QA-4002` / `QA-4003` | 问题 / 回答 / 父评论不存在或已软删除 |
| `REP-1001` | 投票值非法（声誉规则手册拒绝结算） |
| `REP-1002` | 可用悬赏积分不足 |
| `REP-1003` / `REP-1004` | 悬赏积分（10–500）或期限（1–14 天）超范围 |
| `REP-1005` | 发起人不能获得自己发起的悬赏 |
| `REP-1006` / `REP-1007` | 冻结积分不足 / 积分数量必须为正数 |
| `REP-1008` | 问题已删除或已采纳，不能发起悬赏 |
| `REP-2001` | 悬赏已结束，不能再操作 |
| `REP-3001` | 只有课程教师/助教可以发起悬赏 |
| `REP-3002` | 只能查看自己的声誉流水 |
| `DIS-1001` | 搜索关键词每个词项至少 2 个字符（ngram 分词粒度限制） |
| `DIS-1002` | 搜索关键词超过 50 个字符 |
| `DIS-3001` | 只能标记自己的通知为已读 |
| `DIS-3002` | 通知不存在或已被删除 |
| `AUTH-401` | 未登录 |
| `AUTH-403-CSRF` | 缺少或错误的 CSRF 令牌 |
| `AUTH-429` | 登录失败次数过多（1 分钟内 5 次） |

## 完整错误码清单

> 本章由 `grep` 全仓 `src/main` 的错误码字符串生成，与代码一一对应；上方「常用错误码速查」只挑高频项。
> 生成口径：`"(ID|QA|REP|DIS|AUTH|SYS)-数字…"` 后紧跟的中文消息；`src/test` 下的构造用例不计入。

| `ID-1002` | 422 | 昵称不合法（2–20 字，且不能含 @ 或空格） | src · User |
| `ID-1003` | 422 | 邮箱格式不正确 | src · User |
| `ID-1005` | 422 | 学生账号请通过注册流程创建 | src · User |
| `ID-1006` | 422 | 不能修改自己的角色 | src · User |
| `ID-1007` | 422 | 不能禁用自己的账号 | src · User |
| `ID-1010` | 422 | 课程代码应为 2–20 位字母、数字或连字符 | src · Course |
| `ID-1011` | 422 | 课程名称不合法（2–50 字） | src · Course |
| `ID-1012` | 422 | 学期不合法（2–20 字） | src · Course |
| `ID-1013` | 422 | 不能修改课程教师的角色 | src · CourseMember |
