   ADR-009 的「已完成」指渐进式门禁已在 S4 走到最后一级（全模块 0.70 覆盖率门禁），

   「事务性发件箱」，Maven 多模块包结构是 **ADR-010**。经核对**不算缺口**（决策文档存在、内容完整），
   此处保留注记说明 #41 的产物对应 ADR-010，以免后续按编号去翻 ADR-002 时找不到。
