## 四、关于 6 个跳过的集成测试

`co-bootstrap` 的 6 个 IT 在本归档中标记为 skipped：

| 测试类 | 用途 |
| --- | --- |
| `CampusOverflowFlowIT` | S3 完整链路：采纳 → 声誉 → 搜索 → 通知 |
| `QuestionPersistenceIT` | 真实 MySQL 落库 |
| `BootstrapApplicationContextIT` | 真实 MySQL 8 + Redis 7 下的上下文冒烟 |

**原因**：`backend-test-reports` 构件来自 CI 的「后端构建与验证」阶段，该阶段以 `-DskipITs=true` 运行，只跑单测。

**真正的 IT 结果在另一处**：`Testcontainers 集成测试 (Lab7)` 工作流有 Docker 环境，在 `develop` 推送时执行「`#34` 验收 / 真实 MySQL 落库」与「S3 规格 / 完整业务链路」两个作业。这两个作业在同一次提交上均为 success。

准确的说法是：**单测 212 个全通过；集成测试 6 个不在本构件内，在同提交的另一个工作流里通过。**
