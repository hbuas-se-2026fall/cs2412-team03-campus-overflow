## 四、怎么复现

```bash
# 单个模块的测试
cd backend
mvn -o -B -ntp -pl co-qa/co-qa-application -am test

# 覆盖率报告（生成 target/site/jacoco/jacoco.csv）
mvn -o -B -ntp -pl co-qa/co-qa-application jacoco:report

# 前端
cd frontend && npm test
```

汇总 `jacoco.csv` 的口径：`LINE_COVERED / (LINE_COVERED + LINE_MISSED)`，
分支同理用 `BRANCH_COVERED / (BRANCH_COVERED + BRANCH_MISSED)`。

## 五、与门禁的关系

- 门禁只看**行覆盖率 ≥ 0.70**，不看分支；
- 门禁对**没有 `jacoco.exec` 的模块静默跳过**，所以本页第二节那些「之前 0 个用例」的模块，
  在门禁上是**绿的**——这正是需要这张表的原因；
- CI 阶段 2b 有 `jacoco.exec` 存在性断言，能发现「该生成却没生成」的情况，
  但发现不了「模块本来就没有测试」。
