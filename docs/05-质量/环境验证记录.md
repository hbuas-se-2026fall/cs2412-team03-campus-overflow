## 基线说明

- `mvn test` 中由 `TODO(Sx)` 桩方法抛出的 `UnsupportedOperationException`（Failures/Errors）属预期：骨架阶段业务方法尚未实现，不是环境问题，也不需要改测试断言；
- 失败总数随模块实现合并持续下降、不是固定值：`#48`（QA 领域层）合并后当前 develop 实测 `Tests run: 54, Failures 3, Errors 20`（合计 23）；逐人记录以本人本机 `mvn -B -Dmaven.test.failure.ignore=true test` 的 surefire 汇总为准，勿沿用早期固定的 38 旧值；
- 判定口径：失败项全部为 TODO 桩即记“通过”；后端/前端能正常启动即合格（无 Docker 或守护未起如实写“未验证”，不硬填通过）。
