## 回顾

**Keep**

- 破冰 PR 强制每人走一次完整流程，后面提 PR 上手快。
- 分支保护一开始就开 `enforce_admins`，没出现过「管理员直接推」的情况。

**Drop**

- 章节模板留了太多【待填】，`角色承诺书` 交付时表格已经填了，但 `2026-W43-Sprint0计划会.md` 至今是空模板。

**Start**

- 交付物要有明确的路径和文件名，不能只写「提交截图」。
